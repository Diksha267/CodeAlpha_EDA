# CodeAlpha EDA Project

## Project Overview

This project is part of the CodeAlpha Data Analytics Internship. It focuses on Exploratory Data Analysis (EDA) using Python.

## Dataset

Students Performance in Exams, containing student demographic information and mathematics, reading and writing scores.

## Tools and Libraries

* Python
* Google Colab
* Pandas
* NumPy
* Matplotlib
* Seaborn

## Project Objectives

* Explore and understand the dataset.
* Check missing values and duplicate records.
* Perform statistical analysis.
* Identify trends and patterns.
* Visualize data using graphs.
* Analyze correlations between subject scores.

## Conclusion

The project uses Exploratory Data Analysis to understand the dataset, identify patterns and gain insights into student performance.
